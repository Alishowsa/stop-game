# 📖 Sobre o Projeto

O **Stop Game** é um jogo web interativo baseado no clássico jogo de palavras conhecido como **STOP** ou **Adedonha**.

O objetivo do projeto foi praticar conceitos essenciais do desenvolvimento front-end, incluindo:

- Manipulação de DOM
- Eventos JavaScript
- Temporizadores
- Armazenamento Local
- Estruturação de Interface
- Experiência do Usuário
- Lógica de Programação

---

# 🚀 Funcionalidades

✅ Sorteio animado de letras  
✅ Temporizador regressivo  
✅ Sistema automático de pontuação  
✅ Validação dinâmica de respostas  
✅ Feedback visual em tempo real  
✅ Ranking persistente com LocalStorage  
✅ Interface moderna utilizando CSS Grid  
✅ Salvamento dos Top 5 jogadores

# ▶️ Como Executar o Projeto


## Acesse a pasta do projeto

```bash
cd stop-game
```

## Execute no navegador

Abra o arquivo:

```bash
index.html
```

# 🏆 Sistema de Ranking

O jogo possui um sistema de ranking local que:

- Salva pontuações automaticamente
- Organiza os jogadores por maior pontuação
- Mantém apenas os 5 melhores resultados

Utilizando:

```javascript
localStorage
```
